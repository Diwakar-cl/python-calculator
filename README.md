# Python Calculator 🧮

A command-line calculator built with pure Python — no libraries.

## Features
- Add, subtract, multiply, divide (with divide-by-zero guard)
- Immortal loop — keeps calculating until you type `quit`
- Session memory — type `history` to replay every calculation
- Memory stored as structured data (list of dictionaries)

## Run it
`python3 cal.py`

## What I learned
Functions, loops, error handling (try/except), lists, dictionaries,
f-strings — and how to hunt silent bugs like stale variables and None ghosts.
